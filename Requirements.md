# MovieWatch Requirements

## 1. Customer Statement of Requirements

 MovieWatch is a web based application designed for people who want a simple and organized way to manage their movie watchlists. This application will allow users to add,filter,search,delete,view, and manage movies while also keeping track of whether each movie has been or needs to be watched. MovieWatch will help in providing users with an easy to use interface and database for storing movie information. The goal of this application is to help provide a centralized and convenient location for avid movie watchers to keep track of their films.
